### Codec / crypto

- **Pure-Julia canonical CBOR value codec** (`src/cbor.jl`), dispatched by **multiple
  dispatch** on the value type (`String`→mt3 / `Vector{UInt8}`→mt2 / `Integer`→mt0/1 /
  `AbstractFloat`→mt7) — byte-vs-text and int-vs-float are type-distinguished, no side channel.
- **Hybrid numeric model:** native `UInt64` for the CBOR uint64 argument tower `[0, 2⁶⁴−1]`
  (fixed-width → mandatory `[2⁶³, 2⁶⁴−1]` head-form self-test, passes byte-exact) + `BigInt`
  (GMP) for reconstructed application values. Native IEEE `Float64`/`Float32`/`Float16` via
  `reinterpret` + explicit big-endian byte-swap; only the f16 shortest-float ladder is
  hand-decided.
- **Native crypto floor — NO C-ABI:** SHA-256/384 via Julia `SHA` stdlib; Ed25519 via
  **system libsodium through `ccall`** (`crypto_sign_*`) — the native-audited-lib tier
  (Elixir `:crypto` / Haskell crypton class), not the keystone C-ABI FFI-hybrid. Crypto floor:
  **Ed25519 + SHA-256**. Ed448 / SHA-384 agility **deferred** (opt-in via C-ABI `ec_ed448_*`;
  libsodium has no Ed448).
- base58 + LEB128 multikey varint hand-rolled in pure Julia (BigInt long division).

### Concurrency

- Single-threaded **Task scheduler** (cooperative coroutines over the libuv reactor). §7b
  store-safety **structural** — plain `Dict` store mutated only between yield points, no lock.
  §6.11 handler-outbound reentry is a `Channel` handoff keyed by `request_id` — no cross-thread
  demux.
