# Changelog — entity-core-protocol-crystal

All notable changes to this peer. Tracks the Entity Core Protocol spec-data version.

## 0.1.0-pre — 2026-07-12

First generated release. **Tracks Entity Core Protocol v0.8.0 (V8).** Codec corpus v0.8.0.

Generated by the `entity-core-keystone` `/entity-rosetta` pipeline (S1→S5). A **corroboration
/ generator-robustness** peer — the Ruby-overfit check (compiled/typed/fixed-width/CSP-fiber
Ruby-like substrate). A green verdict is cohort-consistent, not independent convergence
(ADR-0012).

### Conformance
- **Codec:** 71/71 byte-identical vs `conformance-vectors-v1` (`9695b1f1…`), sealed offline.
  Plus a fixed-width `[2^63, 2^64-1]` head-form self-test and a libsodium Ed25519
  sign→verify accept-path unit.
- **Live peer:** `validate-peer --profile core` = **292·0F @ cc1970f** (P292 / W294 / F0 /
  S96; 96 skips are §9.0 auto-allowlisted extension carve-outs). §9.5 53/53 type floor.
  Genuine 2-of-3 multisig accept-path (oracle probe `valid_2of3_peer_signed_accepted` runs
  live + passes).
- **Robustness:** 20/20 crash-free repeated `--profile core` runs after the graceful-shutdown
  fix (see below).

### Idiom
- Native hand-rolled canonical CBOR (pure Crystal); fixed-width `UInt64` head-form.
- Ed25519 via a direct in-process libsodium `lib`/`fun` C binding; SHA-256/512 via stdlib
  `Digest`; SHA-384 via `OpenSSL::Digest`.
- CSP fibers + `Channel`s, single OS thread (structural §4.8 store-safety, no mutex at core).
- Exceptions under `EntityCore::Error`; §6.11 `{request_id => Channel}` reentrant demux.
- §4.10 floor: 413 payload_too_large (pre-buffer), 400 chain_depth_exceeded (structural
  pre-check before the authz walk). TCP_NODELAY on every socket.

### Fixed
- **Graceful shutdown (SIGTERM/SIGINT).** The host now traps `SIGTERM`/`SIGINT` and closes the
  listener for a scheduler-intact exit; `run-s4.sh` reaps gracefully. Eliminates an
  intermittent `Thread#execution_context cannot be nil` crash (Crystal 1.20's preview
  Execution-Contexts scheduler interrupted by an unhandled kill under the harness). Verified
  0/20.

### Deferred
- Ed448 / SHA-384 agility (libsodium has no Ed448; future FFI-hybrid via `libentitycore_codec`).
- Registry publish + git tag (operator decision; `0.1.0-pre`).
- `-Dpreview_mt` / Execution Contexts parallelism (still preview in Crystal 1.20).
