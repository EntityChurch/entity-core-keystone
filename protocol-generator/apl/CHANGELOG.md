# Changelog — entity-core-protocol-apl

All notable changes to this peer. Format loosely follows Keep a Changelog; versions track
the Entity Core protocol spec version explicitly.

## [0.1.0-pre] — 2026-07-12

First pre-release. **Tracks ENTITY-CORE-PROTOCOL v0.8.0 (V8)** (core wire byte-unchanged
across the V7→V8 cutover). Generated by the keystone `/entity-rosetta` pipeline as the
**array / value-model alien-substrate probe** (the array-as-primitive-value axis).

### Conformance

- `validate-peer --profile core` → **682 · 0F @ oracle `cc1970f`** (291 P / 295 W / 0 F /
  96 S), `Result: PASS`. Core-gate fingerprint `8261a033…`. The 96 skips are §9.0 extension
  carve-outs, auto-allowlisted by the profile (no skip counts as a FAIL); the 295 warns are
  non-gating (292 matched-if-present type-vocabulary + a tree path-flex advisory + a
  concurrency no-parallel-speedup informational + a `resource_bounds` SHOULD connection-flood).
- Keystone-generated peer sharing the cohort generation lineage — **cohort-consistent, not
  independent convergence** ([ADR-0012]). No spec-vs-oracle divergence; no arch handoff.
- S2 codec: pinned v0.8.0 ECF corpus **69 / 69** byte-identical.
- S3 peer machinery: offline self-test **18 / 18** + two-peer loopback smoke **5 / 5**.
- **Genuine K-of-N multisig accept-path** (`valid_2of3_peer_signed_accepted` PASS — the peer
  co-signs as its provisioned keypair; not env-skipped, not vacuous).
- §6.13(b) handler-outbound dispatch reentry wired live (`concurrency.t1_2`/`t1_3` PASS);
  §4.9 sustained load + churn PASS under the single-thread serialized reentry pump.

### Codec / crypto

- Pure-APL canonical CBOR **value** codec (the array-model probe): base-conversion (`⊤`/`⊥`
  base-256) + grade (`⍋` length-then-lex key sort) over vectors. The `uint64` tower
  `[2⁶³, 2⁶⁴−1]` carried as an 8-octet big-endian array (never `256⊥`'d into a scalar —
  APL silently promotes `≥2⁶³` to lossy IEEE double, sharper than Fortran's controllable
  signed carrier); mandatory boundary self-test on `{0, 2⁶³−1, 2⁶³, 2⁶⁴−2, 2⁶⁴−1}`.
  f64/f32 bits hand-rolled by arithmetic decomposition (no APL bit-reinterpret primitive);
  hand-rolled f16 + shortest-float ladder.
- Crypto / entity-framing / base58 via `libentitycore_codec` **C-ABI 1.1**, bound through a
  GNU APL **native function** (`⎕FX`) C++ shim (`src/ext/ec_native.cc`). Crypto floor:
  **Ed25519 + SHA-256**. Ed448 / SHA-384 agility deferred (opt-in via C-ABI `ec_ed448_*`).
- Transport is native `⎕FIO` Berkeley sockets — **no C net-shim** (unlike COBOL/Fortran);
  single-thread select-pump, structural §7b store-safety.

### Packaging

- Build: GNU APL 1.9 built from the SHA-256-pinned GNU source tarball (not in fedora dnf) +
  `make` driving the native-fn shim compile. The `.apl` source is interpreted, not compiled.
- `make dist` → `dist/entity-core-protocol-apl-0.1.0-pre.tar.gz` (source distribution: the
  `.apl` workspace + `ec_native.cc` shim source + build recipe).
- No package registry (APL has none mature); publish = a git tag. Registry/tag is an
  operator decision after review — the whole cohort is parked at `0.1.0-pre`.

### Known / deferred

- Ed448 / SHA-384 agility deferred (floor is Ed25519 + SHA-256; no native APL Ed448).
- Durable GNU-APL-1.9 idiom cookbook logged across `A-APL-012…017` (no `:If`/dfn-guard under
  `--script`; niladic dfns eval at load; two `⎕FIO[40]` select bugs worked around;
  `⊃`=disclose-not-first, `≡`=rank-sensitive, `⍺∘≡¨⍵`=DOMAIN, label∥variable=SYNTAX) —
  reusable for any future GNU APL peer / generator run. No spec impact.
