# Changelog — entity-core-protocol-fortran

All notable changes to this peer. Format loosely follows Keep a Changelog; versions track
the Entity Core protocol spec version explicitly.

## [0.1.0-pre] — 2026-07-11

First pre-release. **Tracks ENTITY-CORE-PROTOCOL v0.8.0 (V8)** (core wire byte-unchanged
across the V7→V8 cutover). Generated by the keystone `/entity-rosetta` pipeline as peer #25,
the fixed-width SIGNED-ONLY numeric-model alien-substrate probe.

### Conformance

- `validate-peer --profile core` → **682 · 0F @ oracle `cc1970f`** (292 P / 294 W / 0 F /
  96 S), `Result: PASS`. Core-gate fingerprint `8261a033…`. The 96 skips are §9.0 extension
  carve-outs, auto-allowlisted by the profile (no skip counts as a FAIL); the 294 warns are
  non-gating (matched-if-present type-vocabulary + one SHOULD connection-flood WARN).
- S2 codec: pinned v0.8.0 ECF corpus **69 / 69** byte-identical.
- S3 peer machinery: offline self-test **18 / 18** + two-peer loopback smoke **5 / 5**.
- **Genuine K-of-N multisig accept-path** (`valid_2of3_peer_signed_accepted` PASS — the peer
  co-signs as its provisioned keypair; not env-skipped, not vacuous).
- §6.13(b) handler-outbound dispatch reentry wired live (`concurrency.t1_2` PASS); §4.9
  sustained load (160 000 gets) + churn PASS.

### Codec / crypto

- Pure-Fortran canonical CBOR value codec (the numeric probe): `uint64` tower `[2⁶³, 2⁶⁴−1]`
  carried as a 64-bit bit pattern in a signed `integer(int64)` carrier with a `ult()`
  bias-compare and a mandatory boundary self-test; native IEEE `real(real64/real32)` floats
  via `transfer()` + explicit big-endian byte-swap; hand-rolled f16 + shortest-float ladder.
- Crypto / entity-framing / base58 via `libentitycore_codec` **C-ABI 1.1** bound directly
  through `iso_c_binding` (no C wrapper). Crypto floor: **Ed25519 + SHA-256**. Ed448 agility
  deferred (opt-in via C-ABI `ec_ed448_*`).
- The only C wrapper is the socket net-shim (`src/ext/net_shim.c`); single-thread select
  loop, structural §7b store-safety.

### Packaging

- Build: gfortran + `make` (container) with an idiomatic `fpm.toml` for fpm users.
- `make dist` → `dist/entity-core-protocol-fortran-0.1.0-pre.tar.gz` (source distribution).
- Registry publish deferred (operator decision, gated on a community pull) — the whole
  cohort is parked at `0.1.0-pre`.

### Known / deferred

- Ed448 / SHA-384 agility deferred (floor is Ed25519 + SHA-256).
- Build-value heap growth (`A-FTN-013`): measured within the 4 GiB cap under the §4.9
  flood; the bump-arena is documented deferred hardening, not a gate blocker.
- Corpus finding `A-FTN-012`: the `tag_reject.1/2/3/5` corpus vectors reject via trailing-data,
  not the §6.3 tag scanner — routed to arch (see `research/stewardship/`). Real N2 tag
  coverage added in `test/unit_tests.f90`; does not affect the gate.
