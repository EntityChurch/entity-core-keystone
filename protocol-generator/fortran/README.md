# entity-core-protocol-fortran

A full **core-protocol** Entity Core peer in **Fortran** (gfortran 15.2, Fortran 2018 +
selected 2023). Generated by the keystone `/entity-rosetta` pipeline as the cohort's
**fixed-width SIGNED-ONLY numeric-model probe** — the sharpest fixed-width case of the
"integer head-form is a fixed-width artifact, not a protocol property" lesson.

**Conformance:** `validate-peer --profile core` → **682 · 0F @ `cc1970f`**
(292 P / 294 W / 0 F / 96 S) — `Result: PASS`.
See [`status/CONFORMANCE-REPORT.md`](status/CONFORMANCE-REPORT.md) for the full
per-category table and [`status/CONFORMANCE-REPORT.json`](status/CONFORMANCE-REPORT.json)
for the machine record. Tracks **ENTITY-CORE-PROTOCOL v0.8.0 (V8)**.

> Scope: **core Layers 0–4** (substrate, identity, interaction, capability, bootstrap).
> No standard extension (TREE, CONTENT, IDENTITY, ATTESTATION, QUORUM, REGISTRY, RELAY) is
> implemented — the extension surface stops at the dispatcher interface. This is a
> *provided* conformance peer, not a mandate; anyone may build a ground-up implementation.

## What this peer is (the probe)

ECF's canonical wire carries a **binary UNSIGNED** integer tower (CBOR mt0 `uint64`,
network-order octets) with a shortest-head ladder that reaches the full `uint64` range
`[0, 2⁶⁴−1]`. Fortran's widest portable-standard integer is the **signed**
`integer(int64)` — two's-complement, range `[−2⁶³, 2⁶³−1]` — and there is **no portable
unsigned type** (Fortran 2023 adds `UNSIGNED`, gfortran 15 implements it under `-funsigned`,
but it is experimental, flag-gated, and array-index-hostile — declined, see
[`A-FTN-001`](status/SPEC-AMBIGUITY-LOG.md)).

So the octet `[2⁶³, 2⁶⁴−1]` of the tower is carried as a **64-bit BIT PATTERN in a signed
`integer(int64)` carrier**: byte emission uses sign-agnostic bit extraction
(`iand(ishft(v, -8*k), 255_int64)`), never signed arithmetic; the minimal-head decision
uses an unsigned bias-compare (`ult()`), never a bare signed `<`. A mandatory self-test
round-trips every value in `{0, 2⁶³−1, 2⁶³, 2⁶⁴−2, 2⁶⁴−1}` byte-exact. The probe closed as
**corroboration**: the spec's numeric determinism survives a signed-only substrate with no
side channel — which is itself the finding.

Floats are the softer axis: `real(real64)`/`real(real32)` are **native IEEE-754**
(binary64/binary32) with a `transfer()` bits path (tractable, unlike Rexx's fully
hand-rolled floats); only f16 (binary16, no guaranteed native kind) and the shortest-float
ladder are hand-rolled. `transfer()` yields native-endian octets → the codec byte-swaps to
big-endian (network order) explicitly.

## Codec & crypto floor (FFI-hybrid)

- **CBOR value codec — pure Fortran** (`src/cbor.f90`): the numeric probe. No Fortran
  package gives canonical ECF; bit intrinsics (`ishft`/`iand`/`ibits`/`mvbits`/`transfer`)
  over `integer(int8)` byte arrays are the byte assembler.
- **Crypto / entity-framing / base58 — the C-ABI** (`libentitycore_codec`, C-ABI **1.1**):
  no native audited Fortran crypto exists, so the §9.1 signature floor is an FFI obligation.
  Fortran's first-class C interop binds the `ec_*` symbols **directly** via `iso_c_binding`
  interface blocks matching the verbatim `entitycore_codec.h` — **no C wrapper** for crypto
  (cleaner than Rexx's SAA ext / Tcl's stubs shim). `ec_ed25519_{seed_to_pubkey,sign,verify}`,
  `ec_sha256/384`, `ec_encode_ecf`/`ec_content_hash`, and `ec_peerid_{parse,format}` (base58 —
  Fortran has no bignum) all cross `iso_c_binding`.
- The **only** C wrapper is the socket net-shim (`src/ext/net_shim.c`) — Fortran has no
  native sockets. The peer is a single-threaded `select` loop over it; §7b store-safety is
  structural (one image, one thread, no lock); §6.11 handler-outbound reentry is a manual
  correlation-map pump.

**Crypto floor:** Ed25519 + SHA-256 (via `libentitycore_codec` / libsodium). **Ed448
agility is deferred** (opt-in, via the C-ABI `ec_ed448_*` when an adopter scopes it).

## Build

Container-bound (Podman, `fedora:43` base, sealed-offline). gfortran + `make` is the
container build (fpm is idiomatic but not in fedora dnf — [`A-FTN-008`](status/SPEC-AMBIGUITY-LOG.md);
an `fpm.toml` is shipped for fpm users). The `make` targets handle module dependency order
and rebuild `libentitycore_codec` from the FFI repo if absent.

```
make peer          # build the single host binary  -> build/peer  (net-shim + codec linked)
make test          # S2 codec gate: corpus 69/69 + unit suite
make s3            # S3 peer gate: offline self-test 18/18 + two-peer loopback smoke 5/5
make dist          # source tarball -> dist/entity-core-protocol-fortran-0.1.0-pre.tar.gz
```

The reproducible container gates (self-re-exec under capped Podman):

```
./run-s2.sh        # codec corpus 69/69 (byte-identical)
./run-s3.sh        # peer machinery (self-test + loopback smoke)
./run-s4.sh        # validate-peer --profile core  (0 FAIL @ oracle cc1970f)
```

## Run

```
build/peer --name NAME [--port N] [--validate]
```

Loads the peer's Ed25519 identity from `~/.entity/peers/NAME/keypair` (entity-core PEM =
base64 of a 32-byte seed; created if absent), binds the port (`0` = ephemeral, the
default), prints a `LISTENING <port>` readiness line, then runs the single-threaded
select-pump.

- **`--name NAME`** — persistent identity + peer-manager interop (the cohort convention).
- **`--seed HH`** — fallback: one hex byte repeated 32× (deterministic seed).
- **`--validate`** — bootstrap the §7a `system/validate/*` conformance handlers (incl. the
  now-live §6.13(b) `dispatch-outbound` reentry). **OFF by default** — a standing outbound
  originator must not ship in production.
- **`--debug-open-grants`** — degenerate `default→*` seed policy. Deprecated (§6.9a); debug
  only, non-conformant.

**Runtime dependency:** `libentitycore_codec.{so}` (the codec C-ABI, from
`ffi-generator/c-abi/entity-core-codec-ffi-c` in the keystone repo, or any interchangeable
`entity-core-codec-ffi-*` build). Build once with its CMake; point `LD_LIBRARY_PATH` at the
resulting `build/` dir (the binary also carries an `-Wl,-rpath` to it).

## Publish

`0.1.0-pre`. Fortran's living distribution norm is the fpm ecosystem (an `fpm.toml` in a git
repo, discoverable via the fortran-lang registry). Publish = tag a git release carrying this
tree + the `make dist` tarball; registry inclusion is a later, review-gated community step —
**deferred like the whole cohort**. `[publishing] repository_url` is TBD on first publish.
Registry upload is an operator decision after review; `/entity-rosetta` never publishes.
