## [0.1.0-pre] — 2026-07-12

First pre-release. **Tracks ENTITY-CORE-PROTOCOL v0.8.0 (V8)** (core wire byte-unchanged
across the V7→V8 cutover). Generated by the keystone `/entity-rosetta` pipeline as a
**Tier-3 corroboration / generator-robustness peer** on a fresh compiles-to-C substrate.

> **Honest framing (ADR-0012):** Nim shares the cohort's generation lineage — passing the
> author's vectors is **cohort-consistent corroboration, not independent convergence**. No
> fresh spec finding surfaced (the wire-surface discovery well is dry); the value is
> corroborating the settled results on a fresh substrate + exercising generator robustness on
> Nim's novel idiom axes (compile-time-metaprogrammed codec, native-C-interop crypto, ARC/ORC).

### Codec / crypto

- **Hand-rolled pure-Nim canonical CBOR value codec** (`src/ecf.nim`): a `seq[byte]` encoder +
  `openArray[byte]` index-walk decoder, with CBOR major-type dispatch resolved at **compile
  time** via `macro`/`template`/`static:` — zero runtime reflection (the Zig `comptime` result
  on a GC'd, native-C-backend substrate; the peer's headline generator-stress axis). No Nim CBOR
  package gives canonical ECF, so `cbor` is declined (A-NIM-001).
- **Fixed-width numeric carrier:** native `uint64` for the CBOR head form `[0, 2⁶⁴−1]` (mt1
  negatives carried as magnitude + tag). A signed-`int64` carrier would silently overflow the
  `[2⁶³, 2⁶⁴−1]` band → the head-form self-test is mandatory (A-NIM-002); builds with
  `--overflowChecks:on`, every decoder read explicitly bound-checked (unsigned wraps silently).
  Float specials hardcoded; shortest-float ladder via float64→float32→float16 re-decode-compare.
- **Native crypto floor — NO C-ABI:** Ed25519 + SHA-256 via **system libsodium through native
  `{.importc.}` interop** (`src/crypto.nim`; `crypto_sign_*` / `crypto_hash_sha256`). Nim
  compiles to C, so this is in-process native interop (the C peer's exact story), not the
  keystone C-ABI FFI-hybrid. Crypto floor: **Ed25519 + SHA-256**. Ed448 / SHA-384 agility
  **deferred** (opt-in sub-library via C-ABI `ec_ed448_*` or OpenSSL `EVP_PKEY_ED448`; libsodium
  has no Ed448 — A-NIM-004).
- base58 + LEB128 multikey varint hand-rolled in pure Nim (`src/base58.nim`, `src/varint.nim`).

### Concurrency / memory

- Single-threaded **`asyncdispatch`** cooperative event loop (`asyncnet` `Future[T]`). §7b
  store-safety **structural** — plain `std/tables` `Table` store mutated only on the one event
  thread, no lock. §6.11 handler-outbound reentry is an event-loop turn keyed by `request_id`
  through the transport `io.pending` table — no cross-thread demux (A-NIM-006). TCP_NODELAY set
  (the Zig Nagle finding). Real OS threads (`--threads:on`) are the noted out-of-scope
  alternative substrate.
- **ARC/ORC** (`--mm:orc`): deterministic ref-counting + cycle collector; destructors run at
  scope exit, move-based ownership, no stop-the-world pause — a third memory idiom between the
  tracing-GC peers and the manual-free peers.
- Error model: stdlib exceptions with `{.raises: [...].}` compiler-enforced exception sets
  (a lightweight checked-exceptions seam); in-band absent = `Option[T]` (A-NIM-008).

### Packaging

- Build: nimble + `.nimble` manifest (`entity_core_protocol.nimble`); `version = "0.1.0-pre"`
  (the **package** version, NOT the spec version v0.8.0 tracked here). The core peer's
  registered-package surface is **empty** (asyncdispatch/asyncnet/tables/options/unittest are
  stdlib, codec/base58/varint hand-rolled, Ed25519+SHA-256 is system libsodium via `{.importc.}`)
  → `nim c` builds fully offline (`--network=none`). Nim 2.2.2 pinned (tarball sha256 verified,
  A-NIM-005), fallback line 2.0.14.
- CI: `.github/workflows/nim.yml` — Podman offline three-gate runbook (codec 71/71 → loopback
  smoke → `validate-peer --profile core`, asserts `summary.failed == 0`). Committed for
  reviewability; no runner attached, no CD, no publish (deferred cohort-wide).
- Registry publish **deferred** (operator decision, gated on a community pull) — the whole cohort
  is parked at `0.1.0-pre`. nimble is a git-indexed registry; git-URL install works
  pre-registration.

### Known / deferred

- Ed448 / SHA-384 agility deferred (floor is Ed25519 + SHA-256; opt-in sub-library over C-ABI
  `ec_ed448_*` or OpenSSL when an adopter scopes it — A-NIM-004).
- Nim's real OS threads (`--threads:on` + channels) are the noted alternative substrate
  (A-NIM-006), out of scope for `--profile core` (asyncdispatch is more idiomatic for a network
  peer and gives structural store-safety free).
- A-NIM-009 (§4.2 "403" vs §5.2a 401 for an unauthenticated non-connect EXECUTE) remains a
  logged **arch finding** — the peer follows the newer, more specific §5.2a (401) and passes;
  flagged so the two sections stop disagreeing. A-NIM-010 is a doc-note-only observation (a
  vendored MANIFEST's stale "401 capability_revoked" annotation vs the oracle/§5.2a `403`; the
  peer follows the oracle and passes). All A-NIM-001..010 are resolved or owner/escalation-tagged
  (`status/SPEC-AMBIGUITY-LOG.md`).
